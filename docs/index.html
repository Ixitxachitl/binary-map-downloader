Map Tile Baker

Bakes a basemap into the 1-bit MTLB tile blob read by NicheGraphics::MapTiles, entirely in your browser - draw a region per zoom level (or use the whole world), preview how it'll render, then bake and download. Vector mode defaults to OpenFreeMap (free, keyless, no rate limit - © OpenMapTiles, data © OpenStreetMap contributors).

Source

Defaults to OpenFreeMap's current planet endpoint. Paste any other OpenMapTiles-schema vector tile URL to use a different source.
